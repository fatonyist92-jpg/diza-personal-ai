## Native C++ + ONNX INT8
- Model files: 156.8 MiB in published Hugging Face ONNX bundle. Run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38203635661
- C++ engine pinned: netai369/PocketTTS.cpp-multilingual at 3ed176a2b238b7ddb62b4aea4e7469ae4bcc3489. This fork supports the Indonesian bundle's bos_before_voice.npy and bundle.json.
- Real C++ native CPU inference: 1.13s generated audio in 0.75s, peak RAM ~459 MiB. Run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38203915965
- Repeat #2: 1.05s generated audio in 0.50s, peak ~487 MiB. Run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38204001433
- Repeat #3: 1.53s generated audio in 0.61s, peak ~455 MiB. Run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38204027997
- Earlier example: 2.33s generated audio in 0.82s, peak ~516 MiB, but its artifact validation failed due to the Python stdlib wave module rejecting IEEE-float WAV, not because synthesis failed. Run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38203757987
- Float32 WAV is normalized into PCM16 WAV for Call compatibility, verified in successful repeated runs.
- Authenticated gateway for native audio, PCM16 transcoding and URL/voice guardrails: diza-live/pocket-native-lab/native-auth-proxy.mjs. Unit tests: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38204071061
- Actual C++ HTTP server -> authenticated Node gateway -> native voice -> PCM16 WAV: 0.372s response generating 2.25s audio, 200 success and 401 without token, on loopback; run: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38204273957
- One later CI attempt found a cold-start race (503 before C++ was warm). The proxy health endpoint was fixed to query the native backend instead of returning unconditional ready, and the startup script now waits for C++ /health. Security unit regression: https://github.com/fatonyist92-jpg/diza-personal-ai/actions/runs/38204457563
- Quality warning: ONNX generated durations for the same 10-word sentence varied widely (1.05–2.33s), so listen to generated audio before any production voice switch. Speed is not proof of word completeness.

## Hosting verdict
- Render Free, official docs: 512 MiB RAM, 0.1 shared CPU, sleeps after 15min idle. The native peak 455–516 MiB leaves insufficient margin for gateway, OS and concurrency and will be slowed considerably by 0.1 CPU. **Do not deploy to Render Free or declare real-time suitability**.
- Hugging Face compute Spaces creation requires paid plan on new accounts, though CPU Basic hourly price is zero.
- Other small hosting vendors may claim 1–2 GB no-card free always-on, but availability/identity/privacy have NOT been independently verified. **Do not put Call transcript text into unverified hosting**.
- GitHub Actions are only tests, never an always-on production HTTP server. Codespaces is quota-bound and sleeps.

## Next true acceptance gate
Persistent trusted CPU host with >=1.5–2 GB memory and >=1 vCPU, end-to-end authenticated HTTPS, audio-level voice quality comparison and user approval, interrupt/hangup, secure logs, cold starts, and no unapproved payment. Until then preserve the existing production Bloks Call unchanged.
