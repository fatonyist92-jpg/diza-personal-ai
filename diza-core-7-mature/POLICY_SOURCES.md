# Item 7 provider-policy sources

These sources are monitored as policy evidence, not as permission to bypass provider safeguards.

## Venice AI
Official guide:
https://learn.venice.ai/guides/create-images-videos-and-custom-characters-in-venice-ai

Current official wording describes:
- Venice Uncensored as an unrestricted text option
- unrestricted image generation options
- open-source video models that do not censor

Status in Item 7:
- hosted candidate
- explicit lane eligible only while official policy remains compatible
- disabled by default until API onboarding is explicitly configured

## NovelAI
Official image documentation:
https://docs.novelai.net/en/image/

Current public image documentation describes broad creative image generation, but this source alone is not sufficient for Diza to assert an explicit hosted adult-content policy.

Status in Item 7:
- adult policy = unknown
- therefore not eligible for explicit routing until stronger official policy evidence is verified

## RunPod
Official Terms of Service:
https://www.runpod.io/legal/terms-of-service

Current terms prohibit content described as obscene/lewd/lascivious.

Status in Item 7:
- not used as the hosted NSFW production route

## Wan 2.2
Official/open repository:
https://github.com/Wan-Video/Wan2.2

Wan 2.2 supports local image-to-video inference and ComfyUI integration.
Its inclusion in Item 7 refers to self-hosted/local inference capability, not to permission from a third-party hosting service.
